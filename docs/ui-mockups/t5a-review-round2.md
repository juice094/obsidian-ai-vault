## W4 实施要点（规格以此为准）

1. **规格 = d70c7db 版 mockup**。视觉与交互均以五屏 + 注记层为准，
   本文件只做索引，不重复规格。
2. **B1 分支语义是行为红线**：
   - 会话笔记（`AI 会话/` 下）上发送 → append 到当前 md。
   - 普通笔记上发送 → 自动创建新会话 md，chip 内容作为首条 user 消息前缀，
     跳转到新会话笔记继续流式。
   - 普通笔记**绝不被写入聊天内容**。
3. **B2 chip 规则**：会话笔记 → 禁用态「上下文：本会话」；普通笔记 → active chip 指向该笔记（默认开）。
4. **避让参数**：FAB `bottom: 108px`（避让原生底部工具栏）；输入坞展开态 `bottom: 0`。
   实现后须在真机/模拟器核对该偏移，108px 是 mockup 估值，可按实测微调但注记同步更新。
5. **坞状态机**：折叠 FAB → 展开坞 → 发送后收起为「正在生成…」条 → turn 完成/中断恢复展开坞（输入框保持聚焦）。
6. **md 格式**：user callout 带显式标题「你」（`> [!user] 你`），已由 R1 批准；
   解析器无需改动（按 type token 识别）。
7. **归档**：纯手动，W4 不实现任何自动归档/列表/搜索 UI。
8. 轨道归属：W4 属 **Android 注入轨道**（bridge `patches/ai-vault`，修订 3 零新增 UI 模型），
   与桌面插件轨道（侧栏会话列表/设置页）功能集不同步，验收各自独立。
